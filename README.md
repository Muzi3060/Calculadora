A ideia desse mini projeto surgiu com o intuito de me ajudar a praticar POO e me ajudar com questões pessoais. 

O uso dele é simples. Ele calcula utilizando os 4 operadores padrão, e também tem uma funcionalidade que para caso vá pagar alguma divida com alguém, pode colocar quantas pessoas vão participar, e quanto cada um vai pagar. com isso ele calcula quanto cada um vai ter que pagar.
